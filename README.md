# Rewhen — Privacy Policy & Support

The public page behind the **Privacy Policy URL** and **Support URL** fields of the
Rewhen app on the App Store.

Live at **https://ivettewo.github.io/rewhen/**

This repository holds the published page only — a single `index.html`, no app code.

## Editing

Edit `index.html` and commit. GitHub Pages rebuilds the site automatically, usually
within a minute. The page is plain HTML with inline styles: no build step, no
dependencies, and it adapts to the reader's light or dark theme.

If the policy changes in a way that affects users, bump the effective date at the top
of the page and mention the change in the app's release notes.
